# Turtle Art

A colourful spiral design drawn with Python's turtle module.

## Features
- Draws 150 circles that grow in size
- Cycles through four shades of pink
- Black background

## How to run
1. Install Python 3
2. Download `turtle_art.py`
3. Run `python turtle_art.py` (a drawing window will open)

## What I learned
Loops, lists, the modulo operator and the turtle graphics module.
